# Media Mix Modelling (MMM)

## 📊 Overview
Statistical analysis to understand the effectiveness of different marketing channels and optimize budget allocation. Uses regression analysis to quantify the impact of each channel on sales.

## 🎯 Business Question
How should we allocate our marketing budget across different channels to maximize ROI?

## 📁 Project Structure
```
├── data/
│   └── marketing_data.csv          # Weekly spend & sales data
├── notebooks/
│   └── mmm_analysis.ipynb          # MMM with regression
└── README.md
```

## 🛠️ Tools Used
- Python (Pandas, NumPy)
- Scikit-learn (Linear Regression, Ridge)
- Statsmodels (statistical significance)
- Matplotlib / Seaborn (visualization)
