# Sales Performance Dashboard

## 📊 Overview
End-to-end sales analytics project analyzing retail performance across regions, products, and time periods.

## 🎯 Business Question
How can we identify top-performing products and regions to optimize sales strategy?

## 📁 Project Structure
```

│   └── sales_data.csv          # Raw dataset
├── notebooks/

├── dashboard/
│   └── sales_dashboard.pbix     # Power BI file (or link to Tableau Public)
└── README.md
```

## 🛠️ Tools Used
- Python (Pandas, NumPy, Matplotlib)
- SQL (PostgreSQL/MySQL queries)
- Power BI / Tableau

## 📈 Key Metrics
- Revenue & Units Sold
- Month-over-Month Growth
- Average Order Value (AOV)
- Top Products by Region
