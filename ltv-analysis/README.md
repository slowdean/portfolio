# LTV (Lifetime Value) Analysis

## 📊 Overview
Customer Lifetime Value analysis to estimate the total revenue a customer generates over their entire relationship with the company. Includes cohort analysis and predictive modeling.

## 🎯 Business Question
What is the predicted lifetime value of customers, and how can we optimize acquisition and retention strategies?

```

├── notebooks/

└── README.md
```
